# 功能验收对照

以下入口均在本地 Vue 应用中。接口路径统一省略前缀 `/api`。单据的创建、审批、过账、权限变更和 PDF 输出均由 Spring 服务处理。查询筛选和显示列偏好保存在当前浏览器，业务记录保存在 MySQL。

| 页面与操作 | 对应服务端入口 | 主要持久化对象 |
| --- | --- | --- |
| 工作台、本月客户到期、销售汇总、待审核、应收 | `/erp/orders`、`/erp/documents`、`/erp/reports/receivable`、`/erp/register/customer` | erp_order、order_line、business_document、party、master_profile |
| 商品、分类、客户、供应商、计量单位、仓库、运营商、结算方式的列表与维护 | `/erp/register/{family}`、`/erp/register/{family}/{id}` | sku、party、base_reference；master_profile 保留历史及扩展属性 |
| 基础档案 → 编码规则，16 种类型的日期与流水设置、实时预览 | `GET /erp/code-rules`、`PUT /erp/code-rules/{key}` | code_rule、code_sequence、sku.code、party.code、base_reference.code、erp_order.order_code、business_document.doc_code |
| 销售及采购列表、草稿、详情、明细导入与导出、折扣、备注 | `/erp/orders`、`/erp/orders/{id}`、`/erp/reports/sales`、`/erp/reports/purchase` | erp_order、order_header、order_line、order_line_extra、purchase_line_account |

| 采购入库、销售出库、销售退货、采购退货、换货出库 | `/erp/documents`、`/erp/documents/{id}`、`/erp/documents/{id}/transition` | business_document、business_document_line、business_document_card、warehouse_stock、inventory、sim_card、card_location、sim_event |

## 页面字段落库

| 页面 | 持久化字段或来源 |
| --- | --- |
| 商品档案 | sku 的 public_name、spec、category、unit、brand、safety_stock、memo、enabled，与原有 code、name、kind、price 一起保存。门户商品目录使用 public_name 和 enabled。 |
| 客户、供应商档案 | party 的 level、manager、contact、phone、settlement、address、memo、enabled。客户合同到期日保存在 expiry。 |
| 仓库、分类、计量单位、运营商、结算方式 | base_reference 按 family 使用 wh_type、address、manager、phone、locations、parent、symbol、contact、basis、days、memo。 |
| 业务单据商品明细 | business_document_line 按单据、行号保存商品、数量、销售有效期和替换卡号。 |
| 制单时的逐卡配置 | business_document_card 保存 ICCID、移动集团账号、激活日、额度、客户套餐和周期月数。入库后的当前卡档案和对账结果可分别在 sim_card、sim_plan、usage_cycle 等表查询。 |
| 汇总及列表展示 | 可用库存、客户剩余流量、折后金额、应收余额等按原始业务字段计算。登录入口和角色校验共用 account 的 role 与 party_id。 |

## 已走通的路径

- 前端执行 TypeScript 检查与 Vite 构建，后端执行 Maven 打包。使用原生 MySQL 8.4.9 初始化数据库，使用 Spring 会话、CSRF 令牌和真实 HTTP 调用验证写入与查询。
- 审批覆盖无配置审核、多人节点、制单人自审、驳回重提及旧轮次审批拒绝。验证采购入库、销售锁库存及出库、退货和换货后客户原卡权限切换，以及设备盘点和调拨。
- 运营商验证使用两个集团账号和模拟 CT 响应。核对终端卡的周期额度、基线折算、人工修正和撤销，以及集团卡按资费查询。真实移动账号和网络白名单需现场联调。
- 财务验收覆盖采购与销售发票、付款、部分收款、超额核销拒绝和应收变化。中文订单 PDF 验证了草稿起可下载和客户角色禁止访问。
- 浏览器验证了登录、列表列设置、制单表单、入库单详情、客户档案保存后刷新、库存 Excel、卡维护与门户查卡。列表、表单及详情均可通过地址栏中的页面路径独立打开。

## 本版范围

- 租户按独立部署和独立业务库隔离，租户内部共享数据。客户门户按登录用户绑定的客户档案限定数据。设备仅按商品和数量管理，期初业务数据不在本期。
- 两种订单的可配置审批与打印已接通。模板可设置标题、公司、商品编码、交货信息、金额显示和页尾说明。门户不提供单据导出或 PDF。审批配置在每次提交时生成快照，配置变更不改变正在流转的单据。
- 订单出入库按整单审核，退货可以按品项和数量办理。换卡支持同商品、同仓库。其它出入库、盘点和调拨支持按数量管理的设备。分批发货、卡片跨仓调拨盘点、财务红冲和跨发票组合核销尚待扩展。
- 人员权限当前分为管理员、内部业务人员和客户。原 PRD 的自定义细粒度按钮授权、完整安全审计、字典和全局参数中心尚待扩展。基础档案与业务报表覆盖常用字段，尚未覆盖原型所有弹层、字段和批量动作。本版适合本地联调及业务验收。
